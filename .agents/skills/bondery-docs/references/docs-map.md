## Public URLs and docs tabs

The page path under `docs/` becomes the public URL. A folder `index.mdx` maps to the folder URL.
For example `docs/deploy/installation.mdx` is `/docs/deploy/installation`, and
`docs/contributing/index.mdx` is `/docs/contributing`.

A folder with no `index.mdx` renders a folder index page. Each child becomes a tile with its
`description`. `deploy/`, `apps/`, `concepts/`, `bondery/`, `api/guides/`, and `contributing/guides/`
behave this way.

Docs tabs come from the URL prefix. See `apps/website/src/lib/docs-tabs.ts` and `tabForDocsUrl`
in `apps/website/src/lib/docs-search.ts`.

| Tab | URL prefix | Content |
|-----|-----------|---------|
| How to use Bondery | `/docs` and every other path | Welcome, concepts, apps, how-to, changelog |
| Self-host | `/docs/deploy` | Requirements, installation, configuration, operations |
| Integrate | `/docs/api` | API introduction, guides, reference, error codes |
| Develop | `/docs/contributing` | Architecture, setup, conventions |

A misplaced page lands in the wrong tab. `/docs/concepts/people` shows under How to use Bondery.
The same page under `/docs/api/concepts/people` would show under Integrate and mislead integrators.
Treat a wrong tab as a user-visible bug.

## Agent surfaces

The docs site publishes extra views for agents. Do not maintain them by hand.

| Surface | URL | Source |
|---------|-----|--------|
| `llms.txt` index | `/llms.txt` | Generated by fumadocs from the page tree |
| Full text | `/llms-full.txt` | Generated by fumadocs from every page body |
| Markdown page view | `/docs/<slug>.md` | Rendered from `get-llm-text.ts` |

Each markdown view opens with the title, the public URL, the GitHub source URL, and the
`description`. A missing `description` leaves a gap at the top of that view.
