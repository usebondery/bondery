# Filter menus (desktop / webapp)

A filter menu holds one or more filters. The user opens it from a filter button.

Search that sits on the same row, outside the menu, is a separate control.

---

## Reset

Put a Reset button at the top of the menu.
Align the button to the end of that row.
The label is the verb `Reset`.

The button clears every filter inside that menu in one action.
The button leaves a search field outside the menu unchanged.

Disable the button when every filter in the menu is already clear.
