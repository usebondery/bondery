Add a UI language by following the `bondery-i18n` skill at [`.agents/skills/bondery-i18n/SKILL.md`](../../../.agents/skills/bondery-i18n/SKILL.md).

That skill is the procedure. It covers the locale catalog, the Postgres enum, plural forms, the region tag for dates and speech, and the profiles for each shipped language.

English stays the reference. Do not translate the marketing site, the docs, or the legal pages as part of a UI locale.
