## Workflow

1. Fork the repository and branch from `main`
2. Follow [local development setup](./local-setup.mdx)
3. Make your changes; run `pnpm run lint` and relevant checks
4. Open a pull request with a clear description

For bugs or features, [open an issue](https://github.com/usebondery/bondery/issues) first when the approach is not obvious.
