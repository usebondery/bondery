# Biome lint rule decisions

These rules are not enabled in [`biome.json`](../../biome.json). This page records the status for rules that are not part of the enabled baseline, separately from the rules already documented in the coding standards.

## Explicitly off

- `noJsxPropsBind`
- `noUnresolvedImports`
- `useImportExtensions`

## Security

- `noSecrets`

## Node.js

- `noNodejsModules`
- `noProcessGlobal`

## Framework components

- `noQwikUseVisibleTask`
- `noReactNativeRawText`
- `noRestrictedElements`
- `noSolidDestructuredProps`
- `useImageSize`
- `useQwikClasslist`
- `useQwikLoaderLocation`
- `useQwikMethodUsage`
- `useQwikValidLexicalScope`
- `useReactNativePlatformComponents`

## Vue

- `noVueDataObjectDeclaration`
- `noVueDuplicateKeys`
- `noVueImportCompilerMacros`
- `noVueRefAsOperand`
- `noVueReservedKeys`
- `noVueReservedProps`
- `noVueSetupPropsReactivityLoss`

## Performance

- `noDelete`
- `noNamespaceImport`
- `useSolidForComponent`
