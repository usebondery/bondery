## Hardware

| Profile | RAM | CPU | Disk |
|---------|-----|-----|------|
| Floor | 2 GB | 2 cores | 30 GB SSD |
| **Recommended** | **4 GB** | 2 cores | 50 GB SSD |

The default stack is four containers (`webapp`, `api`, `redis`, `db`) plus Traefik or another reverse proxy. Most small teams run comfortably on a 4 GB VPS. Leave headroom if you enable heavy background jobs, large imports, or many concurrent sync clients.

## Software

| Requirement | Notes |
|---|---|
| Docker + Compose v2 | Required |
| DNS | Hostnames for API and webapp (e.g. `api.example.com`, `app.example.com`) |
| TLS | Traefik (e.g. via Dokploy) or terminate TLS on a reverse proxy |

The floor profile runs the stack, and the recommended profile leaves room to grow. Both need two hostnames and a TLS certificate. Nothing else is required.
