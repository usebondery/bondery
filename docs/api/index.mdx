## Base URL

```
https://api.usebondery.com/
```

When self-hosting, use your own API origin (see [Self-hosting → Installation](../deploy/installation.mdx)).

## Authentication

The API works from AI agents, automated imports in custom apps, and any script that holds a credential.

See [Authentication](./authentication.mdx) for session tokens vs long-lived API keys, permission levels, and which routes accept API keys.
