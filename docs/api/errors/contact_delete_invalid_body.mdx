## When this happens

The request failed input validation before the handler ran. Affects **Contacts** operations.

## What your integration should do

Verify contact ids, required body fields, and that the record belongs to the authenticated user.

## What end users should see

Translate with `common.errors.api.contact_delete_invalid_body` when a string exists; otherwise map by domain prefix. Never surface the raw API `message`.

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `invalid_request_error` |
| **HTTP status** | 400 |
| **code** | `contact_delete_invalid_body` |
| **doc_url** | `/docs/api/errors/contact_delete_invalid_body` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation). `agent_message` states the same failure plus how to fix the call, for an AI agent.
