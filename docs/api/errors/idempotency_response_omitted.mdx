## When this happens

The first request with this `Idempotency-Key` finished, but the response was a stream or larger than 1 MiB. The API stored the status only.

## What your integration should do

Do not expect the original body. Send the call again with a new `Idempotency-Key`.

## What end users should see

Show `common.errors.api.idempotency_response_omitted`.

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `conflict_error` |
| **HTTP status** | 409 |
| **code** | `idempotency_response_omitted` |
| **doc_url** | `/docs/api/errors/idempotency_response_omitted` |

The response also sets `Idempotent-Replayed: true`.

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation). `agent_message` states the same failure plus how to fix the call, for an AI agent.
