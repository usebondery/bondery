## When this happens

Generic 404 wrapper when no more specific code applies.

## What your integration should do

Treat as a missing resource. Do not retry blindly — confirm the id and user scope.

## What end users should see

Show a friendly not-found message (`common.errors.api.not_found`).

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `not_found_error` |
| **HTTP status** | 404 |
| **code** | `not_found` |
| **doc_url** | `/docs/api/errors/not_found` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation). `agent_message` states the same failure plus how to fix the call, for an AI agent.
