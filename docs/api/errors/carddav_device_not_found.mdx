title: carddav_device_not_found

last_updated: 2026-11-27
---

## When this happens

You rename, rotate, resume or remove a device, and no device with that id exists for the signed-in account.

## What your integration should do

Read the device list with `GET /me/carddav`, then use an id from that list.

## What end users should see

Translate with `common.errors.api.carddav_device_not_found`. Never surface the raw API `message`.

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `not_found_error` |
| **HTTP status** | 404 |
| **code** | `carddav_device_not_found` |
| **doc_url** | `/docs/api/errors/carddav_device_not_found` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation). `agent_message` states the same failure plus how to fix the call, for an AI agent.
