## When this happens

An unexpected failure occurred while handling the request. Affects **Chat** operations.

## What your integration should do

Log the response `request_id` if present and retry once. Escalate if the error persists — likely a server-side bug or dependency outage.

## What end users should see

Show generic retry copy (`common.errors.api.internal` or `common.errors.apiTemporarilyUnavailable`).

## Response fields

| Property | Value |
|----------|-------|
| **Type** | `api_error` |
| **HTTP status** | 500 |
| **code** | `chat_session_failed_to_delete_session` |
| **doc_url** | `/docs/api/errors/chat_session_failed_to_delete_session` |

The API `message` field is for developers debugging in logs. Product UI must key off `code` (and `details` for validation). `agent_message` states the same failure plus how to fix the call, for an AI agent.
