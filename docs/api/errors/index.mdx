Every failed API response uses a nested `{ error: { type, code, message, agent_message, ... } }` envelope. Use `code` for client-side translation — never show `message` in product UI.

`agent_message` is the recovery instruction for an AI agent: what failed, why, and how to fix the call. Every response carries it, so an assistant can repair its own call without a human. It is not for product UI.
