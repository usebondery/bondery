## What to include

If something is not working as expected, tell us. A short message with these details helps us fix it faster:

- What you did, and what you expected to happen
- What happened instead
- The browser or app you used, and your operating system
- A screenshot, when the problem is visible

## Get in touch

<Accordions type="single">
<Accordion title="Email the Bondery team">

Email [team@usebondery.com](mailto:team@usebondery.com). This is the fastest route, and it works for account, billing, and data questions.

You can also find other contact options on our [website contact page](https://usebondery.com/contact).

</Accordion>
<Accordion title="Open an issue on GitHub">

Open an issue on the repository if you are comfortable with GitHub, or if the problem needs a longer public thread:

[Open an issue](https://github.com/usebondery/bondery/issues)

Include the details listed above, and say which client you used: the web app, the mobile app, the Chrome extension, or the API.

</Accordion>
<Accordion title="Open a pull request">

If you already know what to change, open a pull request. Read [Contributing](contributing/index.mdx) first to set up the monorepo and learn the checks that run before a change merges.

</Accordion>
</Accordions>
