## [Unreleased]

### ✨ Added

- Website: the Claude tile on the landing page now links to Bondery's listing in the Claude connector directory, so visitors can reach the plugin page directly.
- Agents: a Claude Code prompt hook now points the agent at the `bondery-changelog` skill whenever a prompt mentions the changelog, so the skill loads instead of the agent working from memory. The hook lives in `.claude/settings.json`; its script is `scripts/dev/claude-prompt-hook.mjs`.

### 🐛 Fixed

- Mobile app: it could miss a change when two edits to the same account were saved at the same moment. It now receives every change.
- Chrome extension: the API now blocks an outdated extension even when it is signed in. Before, the version check gave up as soon as a request carried a sign-in token, so an old extension kept working against a newer API. An extension below the minimum version now gets "update required", and it can still read `/extension/manifest` to show the update prompt.
- Chrome extension: `/extension/manifest` answers again without a sign-in. It sat behind the session check, so the extension's update nudge never received an answer.
- Mobile app: live sync over WebSocket can connect again. The connection carries only its one-time ticket, and a global check rejected it for having no sign-in token before the ticket was read. The app fell back to slower polling.
- Mobile app: it now receives LinkedIn enrichment, vCard, LinkedIn and Instagram imports, photos set from the Chrome extension, and the profile of a new account. These changes saved fine but never reached the phone. After this update the app reloads all its data once to catch up.
- Website: entering `usebondery.com` without `https://` on a mobile browser showed "page not found" instead of the site. Desktop browsers corrected the address on their own; mobile browsers did not. Plain-HTTP requests to every public domain now get a permanent redirect to HTTPS, in production and in self-hosted Traefik deployments.
