## [1.9.2] - 24.09.2026

### 🔄 Changed

- Self-host: Compose publishes Postgres on `127.0.0.1:5432` for SSH tunnels (not the public NIC). A second stack on the same host must set `BONDERY_INFRA_POSTGRES_HOST_PORT` (beta: `5433`).

### 🤖 CI

- Releases: named RCs (`X.Y.Z-rc.N`, tag `vX.Y.Z-rc.N`) own `:beta` and a GitHub prerelease with a staging extension zip. Clean CalVer `vX.Y.Z` is production (CWS, no zip). Everyday merges to `main` still build `:sha-<short>` only.

### Breaking

- **Postgres host port:** Compose binds `127.0.0.1:5432` by default. If another process already uses that loopback port, set `BONDERY_INFRA_POSTGRES_HOST_PORT`. Production and beta on one VPS cannot share `5432` — set beta to `5433`.
- **Health readiness:** `GET /health/ready` no longer reports `services.posthog`.
